# Vrinda Store Excel Dashboard

## Objective

This project analyzes Vrinda Store sales data using Microsoft Excel to understand sales performance, order trends, customer behavior, and order status distribution. The goal is to build a clean and interactive Excel dashboard that supports basic business decision-making.

## Key Analysis

* Monthly sales and order comparison
* Order status distribution
* Sales by gender
* Order count by age group and gender
* Sales by category, channel, and state
* Customer behavior analysis using age group and gender
